Beim Aufruf der Seite verarbeitet GitHub als Hosting-Anbieter technisch notwendige Verbindungsdaten wie deine IP-Adresse, den Zeitpunkt des Zugriffs und Angaben zu deinem Browser. Dies ist erforderlich, um die Webseite überhaupt ausliefern zu können. Da die USA aus Schweizer Sicht nicht über einen angemessenen gesetzlichen Datenschutz verfügen, stützt sich GitHub für die Datenübermittlung auf das vom Bundesrat anerkannte Swiss-U.S. Data Privacy Framework (Swiss-U.S. DPF), unter dem GitHub zertifiziert ist, sowie ergänzend auf die Standardvertragsklauseln (SCC) der EU-Kommission. Nähere Informationen findest du in den Datenschutzbestimmungen von GitHub.
